# VOX – Cross-Platform Productivity Ecosystem

## Overview
VOX is a cross-platform productivity ecosystem designed to provide a seamless and synchronized workflow across **Android (Kotlin)** and **Windows Desktop (Java)**. It enables secure device pairing, real-time task synchronization, and a unified dashboard experience across devices.

The project emphasizes scalability, clean architecture, and system-level integration, making it suitable as an industry-oriented cross-platform application.

---

## Features
- Secure cross-device authentication using Google sign-in and a pairing code  
- Real-time synchronization between Android and Windows applications  
- Structured task management with a 24-hour task lifecycle  
- Productivity metrics including completed tasks and consistency tracking  
- Unified, modular dashboard for profile, settings, and tasks  
- Architecture designed for future extensions such as voice and gesture controls
